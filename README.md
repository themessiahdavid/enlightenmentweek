# Enlightenment Week

This repository preserves the deployed Enlightenment Week website, including all public routes, compiled application assets, styling, and images from the live project.

## Routes

- `/`
- `/film`
- `/apply`
- `/safety`
- `/privacy`
- `/terms`
- `/contact`

The project is a static snapshot of the deployed site and can be served by any static web server that supports directory index files.
