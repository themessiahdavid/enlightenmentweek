# Enlightenment Week

This repository preserves the deployed Enlightenment Week website, including all public routes, compiled application assets, styling, and images from the live project.

Agent work starts with the shared [project rules and execution contract](AGENTS.md). Authorized Claude, Grok and ChatGPT controller tasks must explicitly read it with the current accepted bounded claim; creating an entrypoint is not proof of runtime loading. Locate the native application source before editing compiled assets; source changes do not deploy the site.

## Routes

- `/`
- `/film`
- `/apply`
- `/safety`
- `/privacy`
- `/terms`
- `/contact`

The project is a static snapshot of the deployed site and can be served by any static web server that supports directory index files.
